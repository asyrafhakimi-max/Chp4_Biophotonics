# Biophotonics – Interactive Lecture Note

Chapter 4 of **NMJ40003 Bioinstrumentation II**, Universiti Malaysia Perlis (UniMAP).
Prepared by **Mr. Asyraf Hakimi**.

An interactive, beginner-friendly lecture note on using light to image, measure and manipulate living matter. Every topic has a plain-language explanation, a hands-on simulation with numbered "Try it" steps, a "What to notice" point, the full lecture detail (tables, formulas, worked examples), and links to real photos. Each part ends with a short self-marking quiz. Works on computers, tablets and phones.

**Open it:** `https://asyrafhakimi-max.github.io/Chp4_Biophotonics/` (after GitHub Pages is switched on).

## Notes
- All graphics and animations are drawn in the page; there are no image files. "See real photos" links open Wikipedia and Nobel Prize pages in a new tab.
- The simulations use simplified models and illustrative numbers for teaching (for example the schematic skin depths and the oximeter approximation SpO₂ ≈ 110 − 25R). They are not for clinical use.
